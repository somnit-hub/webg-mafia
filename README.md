# Mafia Desk

Мобільний local-first помічник ведучого спортивної «Мафії» на 10 гравців. Це статичний PWA без обов’язкового бекенду, збірки та зовнішніх runtime-залежностей, готовий до GitHub Pages.

## Що вже працює

- довідник гравців: ім’я, нік, контакт/клуб, нотатки та аватар;
- локальне обрізання і стискання фото до 512×512 перед записом;
- розсадка 10 гравців і випадкова колода: Шериф, Дон, дві Мафії, шість мирних;
- приватна почергова роздача ролей з одного телефону;
- нульова ніч, денні промови, точний таймер, номінації, голосування, нічиї, останнє слово;
- нічна стрільба, пошук Шерифа Доном і перевірка кольору Шерифом;
- турнірна або клубна система фолів, скасування останніх дій;
- автоматичне визначення перемоги та ручне завершення нестандартної партії;
- протокол, архів, тривалість партій, рейтинг і статистика ролей;
- публічний режим оглядача без ролей та нічних результатів;
- IndexedDB, JSON-експорт/імпорт, офлайн-кеш Service Worker;
- опційний Google OAuth і приватна резервна копія в Google Drive `appDataFolder`.

Початковий [sport_mafia_10_ua.html](./sport_mafia_10_ua.html) залишено як референс. Робоча точка входу нового застосунку — [index.html](./index.html).

## Локальний запуск

ES-модулі та Service Worker потребують HTTP, тому не відкривайте `index.html` через `file://`.

```powershell
python -m http.server 8080
```

Після цього відкрийте `http://localhost:8080`.

## GitHub Pages

У репозиторії є workflow [pages.yml](./.github/workflows/pages.yml). Після першого push:

1. Відкрийте **Settings → Pages**.
2. У **Build and deployment → Source** виберіть **GitHub Actions**.
3. Push у `main` опублікує статичний застосунок.

Усі URL у проєкті відносні, тому він працює і за адресою виду `https://USER.github.io/REPOSITORY/`.

## Налаштування Google OAuth

Google не може видати універсальний Client ID разом із репозиторієм: його створює власник майбутнього домену.

1. Створіть або виберіть проєкт у Google Cloud Console.
2. Увімкніть **Google Drive API**.
3. Налаштуйте **OAuth consent screen / Google Auth Platform**.
4. Створіть OAuth client типу **Web application**.
5. Додайте до **Authorized JavaScript origins**:
   - `http://localhost:8080` для локальної перевірки;
   - `https://USER.github.io` для GitHub Pages;
   - origin власного домену, якщо він буде підключений.
6. Скопіюйте Client ID виду `…apps.googleusercontent.com` у **Mafia Desk → Ще → Google OAuth + Drive**.

`client_secret` не потрібен і його не можна додавати в HTML/JavaScript. Застосунок використовує browser token model Google Identity Services. Короткоживучий access token тримається лише в пам’яті вкладки; після перезапуску потрібно увійти знову. Запитується вузький scope `drive.appdata`, а не доступ до звичайних файлів Drive.

## Модель даних і приватність

Основне джерело даних — IndexedDB `mafia-desk`:

| Store | Вміст |
|---|---|
| `players` | постійні профілі та стиснені аватари |
| `games` | активні партії, снапшоти складу, ролі, події та фінальний результат |
| `settings` | таймери, UX-параметри, публічний Google Client ID, час sync |

Склад гравців копіюється в партію на старті. Тому перейменування або видалення профілю не переписує історичний протокол. Дані не відправляються автору проєкту або на сторонній сервер. Виняток — ручна команда резервного копіювання в Google Drive самого ведучого.

Режим оглядача є захистом від випадкового показу секретів, а не криптографічною межею: він призначений для другого дисплея в тому самому довіреному браузері. Не давайте глядачам доступ до DevTools чи локального профілю браузера ведучого.

## Відомі межі та наступні кроки

1. **Live на різних пристроях.** GitHub Pages не має каналу реального часу. Поточний observer mode синхронізує лише вкладки одного браузера через `BroadcastChannel`. Для телефонів глядачів потрібен опційний room-backend (Firebase/Supabase/Cloudflare Durable Objects) із публічною санітизованою проєкцією гри.
2. **Турнірні очки.** Правила нарахування додаткових балів різняться між лігами. Варто додати окремі конфігуровані rulesets після затвердження формули конкретного клубу.
3. **Хмарні конфлікти.** Нинішня Google-копія — ручний last-write-wins backup. Для кількох пристроїв потрібні ревізії, preview змін і merge за `updatedAt`.
4. **Фото й квота.** Аватари оптимізовані, але велика база збільшує JSON backup. Наступна оптимізація — окремі blobs і дедуплікація за hash.
5. **Автотести.** Перед турнірним використанням бажано формалізувати правила ліги й покрити state machine сценаріями: подвійна нічия, кілька останніх слів, 4-й фол і перемога під час ночі.

## Перевірка перед релізом

- запустити повну тестову партію на iPhone Safari та Android Chrome;
- встановити PWA, вимкнути мережу й перезавантажити після першого онлайн-відкриття;
- перевірити OAuth саме з production origin;
- зробити JSON export, очистити тестовий профіль браузера й перевірити import;
- пересвідчитися, що публічний екран не показує ролі, приховані записи та результати нічних перевірок.
